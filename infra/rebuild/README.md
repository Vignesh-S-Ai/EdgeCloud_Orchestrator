# Rebuild Configuration

## How to Use

1. Copy `rebuild.env.example` to `rebuild.env`
2. Run `bash scripts/00-collect-outputs.sh` to auto-fill from Terraform + AWS CLI
3. Or manually fill in each value
4. Source before running any rebuild script: `source rebuild.env`

## Value Sources

| Value | Source | Command |
|-------|--------|---------|
| AWS_ACCOUNT_ID | AWS CLI | `aws sts get-caller-identity --query Account --output text` |
| CLOUD_PUBLIC_IP | Terraform | `terraform output -raw ec2_public_ip` |
| CLOUD_PRIVATE_IP | AWS CLI | `aws ec2 describe-instances --filters Name=tag:Name,Values=edgecloud-cloud-node --query 'Reservations[].Instances[].PrivateIpAddress' --output text` |
| EDGE_PUBLIC_IP | Terraform | `terraform output -raw edge_node_public_ip` |
| EDGE_PRIVATE_IP | AWS CLI | `aws ec2 describe-instances --filters Name=tag:Name,Values=edgecloud-edge-node --query 'Reservations[].Instances[].PrivateIpAddress' --output text` |
| ECR_REGISTRY | Computed | `${AWS_ACCOUNT_ID}.dkr.ecr.${AWS_REGION}.amazonaws.com` |
| CLOUD_NODE_NAME | AWS CLI | Private DNS of cloud EC2 instance |
| EDGE_NODE_NAME | Constant | `edge-ec2-node` (set during EdgeCore configuration) |
| KUBEEDGE_VERSION | Constant | `v1.23.1` |
| K3S_VERSION | Constant | `v1.32.13+k3s1` |

## Scripts

| Script | Purpose | Destructive? | Manual Step? |
|--------|---------|-------------|-------------|
| 00-collect-outputs.sh | Collect all values from Terraform + AWS | No | No |
| 01-ecr-login.sh | Authenticate Docker to ECR | No | No |
| 02-build-images.sh | Build all 4 Docker images | No | No |
| 03-push-images.sh | Push images to ECR | No | No |
| 04-install-k3s.sh | Install K3s on cloud node | No | SSM access required |
| 05-install-kubeedge.sh | Install CloudCore + EdgeCore | No | SSM access to both nodes |
| 06-deploy-k8s.sh | Apply all Kubernetes manifests | No | kubectl access required |
| 07-configure-rules.sh | Create KubeEdge Rules + RuleEndpoints | No | kubectl access required |
| 08-validate.sh | Run full validation | No | kubectl access required |

## Secrets

This directory contains NO secrets. All secrets are:
- Generated by Terraform (database password)
- Generated at runtime (ECR token, KubeEdge token)
- Stored in AWS Secrets Manager
