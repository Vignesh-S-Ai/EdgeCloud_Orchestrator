## Source Code Patches (3 applied)

### Patch 1: processQuery feedbackError (LeaseResp fix)

**File:** `edge/pkg/metamanager/process.go` — `processQuery()`
**Fix:** When `requireRemoteQuery(resType)` is true but `connect.IsConnected()` returns false, now sends `feedbackError("cloud connection not ready")` instead of falling through to local SQLite DB.
**Effect:** Prevents `LeaseResp` array unmarshal error by ensuring queries always go through the remote path when cloud connection is expected.

### Patch 2: imitator.go Kind Injection

**File:** `edge/pkg/metamanager/metaserver/kubernetes/storage/sqlite/imitator/imitator.go` — `Event()`
**Fix:** When decoding an object, if `apiVersion` or `kind` is missing from the JSON, injects them for known resource types (node, configmap, secret, pod, lease).
**Effect:** Prevents `Object 'Kind' is missing` error that prevented the imitator from caching objects.

### Patch 3: processPatch synchronous response

**File:** `edge/pkg/metamanager/process.go` — `processPatch()`
**Fix:** When source is `EdgedModuleName`, calls `processRemote()` instead of just `sendToCloud()`. This makes PATCH calls synchronous — the response is waited for and returned to the caller.
**Effect:** Kubelet PATCH calls (node status, pod status) get proper responses instead of timing out. Without this, kubelet node status updates failed silently.

## WSL2 Session Cascade (Platform Limitation)

### Problem

Every SSM session creates a `session-XXX.scope` in systemd. When the session ends, WSL2's systemd cascades: `session scope → multi-user.target → shutdown.target → final.target → all processes SIGTERM → WSL2 VM reboots`.

### Mitigation (what we implemented)

1. **`basic.target` placement:** Edge services (`edge-containerd`, `edgecore`, `edge-mosquitto`) are `WantedBy=basic.target`, NOT `multi-user.target`. This ensures they auto-start after every WSL2 reboot.
2. **`DefaultDependencies=no`:** All edge services use `DefaultDependencies=no` to avoid being tied to the multi-user.target shutdown chain.
3. **`Restart=always`:** All services restart automatically if killed.
4. **`ExecStartPre` socket wait:** EdgeCore waits for containerd socket before starting.
5. **`Containerd service masked`:** Original `containerd.service` (WantedBy=multi-user.target) is masked to prevent conflicts.

### Impact

- **Downtime per cascade:** ~60-90 seconds (WSL2 reboot + service startup + WebSocket reconnect)
- **Pod survival:** Pods survive through Kubernetes tolerations (300s `NoExecute` tolerance)
- **Node recovery:** Node reaches Ready state automatically after each reboot
- **Root cause:** WSL2 platform-specific behavior — does NOT occur on dedicated Linux hardware

### Production note

For production deployment, use a dedicated Linux machine or IoT device — the session cascade does NOT affect standard Linux systems.

## Systemd Service Files (WSL2)

### /etc/systemd/system/edge-containerd.service
```ini
[Unit]
Description=Containerd (edge node)
DefaultDependencies=no
After=network.target
Wants=network.target

[Service]
Type=simple
ExecStartPre=/sbin/modprobe overlay
ExecStart=/usr/bin/containerd --config /etc/containerd/config.toml
Restart=always
RestartSec=5
KillMode=process

[Install]
WantedBy=basic.target
```

### /etc/systemd/system/edgecore.service
```ini
[Unit]
Description=KubeEdge EdgeCore
DefaultDependencies=no
After=network.target edge-containerd.service
Requires=edge-containerd.service

[Service]
Type=simple
ExecStartPre=/bin/bash -c 'while [ ! -S /run/containerd/containerd.sock ]; do sleep 1; done'
ExecStart=/usr/local/bin/edgecore
Restart=always
RestartSec=10
KillMode=process
LimitNOFILE=65535

[Install]
WantedBy=basic.target
```

### /etc/systemd/system/edge-mosquitto.service
```ini
[Unit]
Description=Mosquitto MQTT (edge node)
DefaultDependencies=no
After=network.target

[Service]
Type=simple
ExecStart=/usr/sbin/mosquitto -c /etc/mosquitto/mosquitto.conf
Restart=always
RestartSec=5
User=mosquitto

[Install]
WantedBy=basic.target
```
